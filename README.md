# Projeto-4-Bimestre-

#Objetivo:
testar seus conhecimentos sobre o Brasil. Você responde 8 perguntas sobre geografia, história e cultura e tenta acertar o máximo possível. No fim, o quiz mostra quantas você acertou.


#Tecnologias utilizadas: 
Figma - para o design 
HTML - para back end 
CSS - front end


#Como utilizar:
Abra o arquivo quiz-brasil.html no navegador (Chrome, Edge, Firefox etc.). Basta dar dois cliques nele.
Leia a pergunta e clique na alternativa que você acha correta (A, B, C ou D).
A resposta aparece na hora. Se você acertou, a alternativa fica verde. Se errou, a sua fica vermelha e a certa fica verde.
Depois de responder, aparece uma curiosidade sobre o tema. Cada pergunta aceita uma única resposta, então pense bem antes de clicar.
Siga descendo a página até a pergunta 8.
A barra de baixo mostra seus acertos em tempo real, por exemplo "Acertos: 3 de 8".
Quando você responder todas as perguntas, aparece a mensagem "Fim do quiz!" com sua pontuação final.
Para jogar de novo: clique no botão amarelo Recomeçar, na barra de baixo, e depois no link "volte ao início" (ou role a página até o topo).
